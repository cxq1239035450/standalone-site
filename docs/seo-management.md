# SEO 与 AI 输出管理

入口：后台「SEO 与 AI 搜索配置」。详情页四张卡片分别查看 sitemap、canonical、robots 和 llms.txt；编辑按钮打开完整配置弹窗。预览、刷新和失败重试均保留在弹窗内。

## 编辑和发布

- 全站配置支持保存草稿、发布和撤回；尚未首次发布或撤回后，公开读取使用安全默认值，不输出未发布域名与爬虫规则。预览版本可切换「当前已发布」与「已保存草稿」，未保存表单不包含在预览中。
- 正式站点 URL、索引/抓取开关、站点地图范围、其他爬虫规则属于共享配置；品牌介绍、AI 简介和推荐栏目在内容翻译中按语言编辑及发布。
- 首页、商品/文章列表、联系和搜索等固定页面使用系统路由生成规范地址；旧 CMS 同名页面记录不会覆盖它们，预览会明确提示。
- 商品、文章、页面翻译中的 Canonical 地址留空自动生成；覆盖值必须为无凭证、查询参数、锚点的 HTTP(S) 地址。保存草稿后可点击「查看 canonical」。
- 站点地图只纳入已启用语言和已发布内容；noindex、非自身 canonical、未选内容类型会排除。后台预览展示排除原因。
- 抓取与索引分开控制。需要搜索引擎读取 noindex 时应允许抓取；同时关闭时后台显示冲突提示。robots 不是访问控制。
- 其他爬虫规则使用每行一个路径。通用爬虫、GPTBot、ClaudeBot 由主开关控制，后台、API、搜索和查询参数路径默认排除。
- llms.txt 按语言显示已发布简介和推荐栏目；推荐内容用关联选择，按数组顺序输出。未发布、禁用语种、noindex 和非自身 canonical 内容不会成为公开推荐链接。
- 预览 API `/api/seo/preview` 仅登录用户可访问，响应不缓存；公开 `/sitemap.xml`、`/robots.txt`、`/llms.txt` 不使用编辑预览身份读取草稿。

## 数据库升级

迁移文件：`20261029_171455_seo_discovery`。需要已完成动态多语言结构迁移；不会再次搬迁已有翻译。旧全站配置保留为已发布版本，旧关闭索引的站点同时保留禁止抓取的行为，管理员之后可分别调整。

先停止目标库写入和定时任务，备份数据库与上传文件，并恢复至独立副本验证。确认本次命令的 DATABASE_URL 指向正确副本。备份必须是绝对路径、存在且非空；脚本不代替恢复验证。

```bash
# 默认仅检查，不修改数据库
pnpm migrate:seo

# 检查通过后，执行本次增量迁移
pnpm migrate:seo --apply --backup="C:/backups/pre-seo.dump"

# 再次执行应显示 already-applied
pnpm migrate:seo
```

该脚本适用于已完成多语言结构、但只有旧 dev 迁移历史的数据库：核对基线列、拒绝部分应用，在同一事务中执行本次迁移并登记本次记录，不伪造旧历史记录。历史迁移记录完整的环境也可以使用常规 `pnpm payload migrate`。不要在旧 dev 库直接重跑所有历史迁移。

完成副本验收后，用同一流程升级正式库，再启动新版本。数据库回滚需停止写入，恢复已验证的数据库和媒体备份后切回旧代码；本次 down 不删除配置和历史。
