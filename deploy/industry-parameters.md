# 行业参数模板

在后台的 **行业参数模板** 中维护可复用参数结构，再到 **产品 → 行业参数模板** 中选择。每个产品可填写不同参数值。

模板可以配置展示标题、参数顺序、名称、文本/数字/下拉类型、单位、输入提示及是否必填。字段标识和下拉选项值用于关联已有数据，应保持稳定；显示名称可分别维护中文和英文。不同产品类别也可建立独立模板，例如宠物服装与宠物玩具。

产品参数按模板及内容语言分别保存。切换模板会保留之前填写的数据，切回可继续使用。清空模板后，产品详情页不显示行业参数。前台及产品 JSON-LD 仅输出当前模板的有效非空值；数字 0 会正常显示，下拉框输出选项名称。

已有产品不必选择模板。必填参数在发布时校验，允许先保存未填写完整的草稿。被产品使用的模板不能直接删除，应先解除产品关联。

## 产品 SEO / GEO 与实时效果预览

产品编辑页的 **SEO / GEO 与效果预览** 可填写页面标题、描述、目标出口/销售市场、制造产地。预览卡片随当前表单实时更新，支持桌面和手机宽度；URL 使用全站 SEO 配置的正式域名、当前内容语言及产品 Slug。Slug 仍在产品编辑页右侧维护。已发布产品修改 Slug 后应安排旧地址重定向。

标题留空使用产品名称，品牌名称由全站配置自动追加。描述留空依次使用产品简短描述、事实摘要、全站默认描述。预览与前台共用标题及描述格式化逻辑。全站或当前产品关闭索引时，预览会明确显示 noindex 状态。

产地与市场按语言独立保存，前台可见，并作为 Product JSON-LD 的 PropertyValue 输出。预览将这些信息置于单独的采购信息区。卡片是模拟效果，不代表搜索引擎必然按此格式展示、收录或排名。

## 初始化示例模板

```sh
pnpm exec tsx src/scripts/seed-industry-templates.ts
```

此脚本创建机械设备、鞋类、宠物用品三组中英文模板，不更改产品内容；同名模板已存在时跳过。初始模板的字段均非必填，管理员可按业务要求调整。

## 部署

此功能新增模板表、产品关系字段、按语言保存的 JSON 参数、产品 GEO 字段及对应版本字段。开发环境会按 Payload 配置同步结构。生产环境需先备份、应用经审阅的增量数据库迁移，再部署代码并初始化模板。不能仅更新代码而跳过数据库变更，也不要用本地数据库覆盖生产数据。
